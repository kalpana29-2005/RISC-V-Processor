# 🧠 RISC-V Processor Design

## 📌 Overview

This project implements a **basic RISC-V processor** using hardware description concepts. It demonstrates the core architecture and working of a RISC-V CPU, including instruction execution, control flow, and data path design.

The goal of this project is to understand **processor design fundamentals** and apply concepts used in **VLSI / RTL design roles**.

---

## 🚀 Features

* ✔️ Implementation of RISC-V instruction set (basic subset)
* ✔️ Modular design (ALU, Control Unit, Registers, etc.)
* ✔️ Instruction Fetch, Decode, Execute stages
* ✔️ Arithmetic and Logical Operations
* ✔️ Clean and structured RTL design

---

## 🏗️ Architecture

The processor consists of the following main components:

* **ALU (Arithmetic Logic Unit)**
  Performs operations like addition, subtraction, AND, OR, etc.

* **Register File**
  Stores intermediate data and operands.

* **Control Unit**
  Generates control signals based on instruction type.

* **Instruction Memory**
  Holds the program instructions.

* **Data Memory**
  Used for load/store operations.
